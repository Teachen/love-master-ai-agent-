### 本次踩的两个坑（重要经验）
1. **打桩 `with_structured_output` 必须返回 Runnable，不能返回裸函数**
   真实 API 返回 Runnable（有 `.invoke`），裸函数会导致 `'function' object has no attribute 'invoke'`。
   正确写法：`return RunnableLambda(_invoke)`。
2. **传入 `invoke` 的 messages 必须全为 BaseMessage，不能混元组**
   元组 `("system", ...)` 不会被解析成消息，导致内容断言失败。
   正确做法：用 `ChatPromptTemplate.from_messages([...]).format_messages(...)` 统一解析；
   `MessagesPlaceholder("history", optional=True)` 处理空历史。
